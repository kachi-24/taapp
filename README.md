# 📅 AI Smart Timetable & Personal Assistant

An AI-powered timetable, scheduling, and productivity mobile application built with **React Native**, **Expo**, **TypeScript**, **Supabase**, and Artificial Intelligence.

The application helps students, professionals, and teams organize their daily activities using intelligent scheduling, voice commands, smart reminders, alarms, notifications, and AI assistance.

## Setup

```bash
npm install
cp .env.example .env   # then fill in your Supabase project values
npm run dev            # or: npx expo start --web
```

`EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY` are required — the app throws at startup without them.
